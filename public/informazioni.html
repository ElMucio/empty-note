Informazioni sul sito

Cos'e' Empty Note

Empty Note e' un'applicazione web che funziona come un bloc-notes online: permette agli utenti registrati di scrivere, organizzare e conservare le proprie note personali, raggiungibili da qualsiasi dispositivo.

Il nostro obiettivo

L'obiettivo del sito e' offrire uno strumento semplice e soprattutto sicuro, per avere sempre a disposizione i propri appunti, senza il rischio di perderli e con anche la possibilita' di esportarli/salvarli anche in locale.

Tecnologie adottate

Il sito e' realizzato con HTML, CSS e JavaScript per la parte visibile all'utente; il server e' un'applicazione Node.js con Express, collegata a un database MySQL in cui vengono archiviati utenti e note.

Trattamento dei dati personali

I dati forniti in fase di registrazione vengono usati unicamente per la gestione dell'account. Le password non sono mai memorizzate in chiaro, ma protette tramite hashing; anche il contenuto delle note viene cifrato prima di essere salvato nel database.
